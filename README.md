# thmsetup

A comprehensive reconnaissance tool for Kali Linux that combines Nmap, Feroxbuster, WhatWeb, Nikto, and more.

## Features
- Automated multi-tool scanning
- Organized output directories
- Support for Web, SMB, and Password scanning modes

## Installation
bash
git clone https://github.com/mustafamix/thm.git
2. Make it executable: `chmod +x thm`
3. Move to bin: `sudo mv thm /usr/local/bin/`
